# Table rules

How we play together, out of character.

## Safe word
If you are uncomfortable or need to step out of the game, say **LIGHTHOUSE**. No questions asked, we pause or move on.

## Dice
A die that falls off the table or lands cocked gets rerolled.

## Missing players
If two players (or the DM) can't make it, the session is skipped. If one player is missing, we play a one-shot with pre-generated characters.

## Snacks
Whoever hosts provides drinks. Everyone else brings snacks.
